# Save the Date: Harsh & Stuti

Live: https://hbarbhaya3-a11y.github.io/Save-the-Date/harsh-stuti/

A baby-pink and ivory animated invitation (~31 s, 9:16), built from the chosen mood board items:

| Time | Scene |
|------|-------|
| 0–3 s | Opening mark: minimal **H & S** with divider (logo option 4) |
| 3–8 s | Couple photo in an arched frame with a slow zoom; "A new chapter together" writes on |
| 8–15 s | Calendar card: a heart hops across November to land on the **30th** |
| 15–20 s | Name reveal: *Harsh & Stuti* · SAVE THE DATE · 30th NOV 2026 |
| 20–25 s | Venues: Roots Cafe and Shri 1008 Mallinath Jain Temple photos, Gurgaon |
| 25–31 s | Final card: floral **H \| S** monogram (logo option 1), names, date |

- `harsh-stuti-reel.mp4` is a 1080×1920, 30 fps MP4 for Instagram Reels and WhatsApp Status.
- Add `#reel` to the URL for a clean, looping frame for screen recording.
- Edit `CONFIG` at the top of `script.js` to change names, date or city.
- Swap the files in `assets/` for higher-resolution versions: `photo.jpg`, `cafe.jpg`, `temple.jpg`, `background.webp`, `florals.webp`.
